# Early-EEG-predictors-for-anxiety-and-drepession

Readme information for paper 'Early electroencephalographic predictors of differentiation and susceptibility for anxiety and depression during childhood and adolescence'.

- 'dgz_CPM_procedures.m' is the code for running connectome-based modeling in this paper.
- 'dgz_longitudinal_permutation.m' is the code for leave-one-out permutation procedures.
- 'predict_behavior_longitudinal_forplot.m' is the function to pack CPM procedure for permutation.
- 'dgz_PERM_extraction.m' is the code for results extraction of permutation procedures.
- 'dgz_mediation.m' is the code for mediation analyses in this paper.
- We provided 'sortForMediation2idx.m' for the reference code of mediation results sortation.
- We also provided the reference example how we plot the results in 'dgz_Fig2_PlotBrainplot.m', 'dgz_Fig2_PlotChardal.m', 'dgz_Fig2_PlotDistribution.m' and 'dgz_Fig4_raincloud.m'.
- 'data' folder contained the needed data and results, while 'toolbox' folder contained the the custom function we used.
